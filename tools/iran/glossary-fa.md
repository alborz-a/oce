# واژه‌نامه تخصصی فارسی (Iranian Construction Glossary)

| اصطلاح انگلیسی | معادل مصوب / تخصصی | توضیحات و کاربرد |
|---|---|---|
| **BOQ (Bill of Quantities)** | فهرست مقادیر و بها | جداول استاندارد احجام و قیمت‌های اقلام کاری پروژه |
| **Estimate** | برآورد | برآورد اولیه یا تفصیلی هزینه اجرای عملیات ساختمانی |
| **Cost Item / Position** | ردیف بها | ردیف مشخص در فهرست بها شامل شرح، واحد و بهای واحد |
| **Takeoff** | متره | محاسبه احجام و اندازه‌گیری کمی مصالح و عملیات اجرایی |
| **Progress Payment** | صورت‌وضعیت | صورت‌وضعیت کارکرد دوره‌ای پیمانکاران جهت تسویه مالی |
| **Contract** | پیمان / قرارداد | قرارداد حقوقی و اجرایی فی‌مابین کارفرما، مشاور و پیمانکار |
| **Price List / Catalog** | فهرست بها | فهرست بهای پایه سازمان برنامه و بودجه یا فهرست بهای خاص شرکت |
| **Overhead** | بالاسری | ضریب بالاسری (شامل هزینه‌های اداری، مدیریتی و سود) |
| **VAT** | مالیات بر ارزش افزوده | مالیات مصوب قانونی بر ارزش افزوده کالاها و خدمات (۱۰٪) |
| **Subcontractor** | پیمانکار جزء | پیمانکاران دست دوم مجری بخش‌های تخصصی کار |
| **Tender / Bid** | مناقصه / پیشنهاد قیمت | فرآیند استعلام قیمت، مقایسه پیشنهادها و انتخاب برنده |
| **Currency** | ریال (﷼) | واحد پولی رسمی با نماد استاندارد ﷼ (U+FDFC) بدون اعشار |
| **Calendar** | گاه‌شمار هجری شمسی | تقویم جلالی با شروع هفته از روز شنبه و تعطیلی روز جمعه |
